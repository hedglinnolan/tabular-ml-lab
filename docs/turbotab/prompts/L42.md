# Part B — the field granularity · the substantial build

**Extend the standing check downward. Do not replace it** — it works at its own level, its
`NOT_READ_BY_THE_DOOR` exemptions are correctly reasoned, and its twice-written comment is a record
worth keeping.

**The question B answers:** for every field the server composes into a payload the door fetches,
**does anything read it?**

Three things make this hard, and each has a precedent that tells you how to handle it:

1. **A literal search cannot answer it.** The existing check's own comment records why: `runPull`
   composes `"/evidence/" + endpoint`, so a path that is fetched on every press appears nowhere in
   the file. Fields are worse — `f.severity` is read as `f[k]` in a loop as often as by name. **The
   harness is the honest instrument**, and `__harness.render()` plus a drive tells you what actually
   reached the DOM.

2. **A field can be read and still not reach a person.** `GUIDED-142`'s findings were *in* an array
   the page iterated; the filter dropped them. So the check is not "is this key referenced" but
   **"does a value that only this field could produce appear in what the page rendered?"** That is
   the `GUIDED-081` lesson — the harness silently dropped every `className` write, so an assertion
   about styling came back passing.

3. **The enumeration must be derived, not hand-listed.** A hand-maintained list is what
   `register.py`'s docstring exists because of — the register was a markdown table until a merge
   blind-copied an older one over it and a whole section vanished silently. Derive the field set
   from the live payloads, so **a field added next loop with no reader fails here** rather than
   being found by the loop after.

**Every unread field resolves to one of three dispositions, and there is no fourth:** rendered
(name where), exempt (name the reader — `NOT_READ_BY_THE_DOOR`'s pattern, and `READERS` is its
vocabulary), or **a ledger row**. An unread field with none of the three is the state this whole
part exists to end.

**Report the counts**: payloads swept, fields enumerated, fields reaching a person, fields exempt
with a named reader, fields unread and filed. **The last column is the finding.**

`GUIDED-138` (`blocks_substitution` has no consumer, with a strict `xfail` naming it) and
`GUIDED-137` (three annotations labeled `(95% CI)` and no interval computed) are both this shape.
**If the sweep names them, close them. Do not go hunting for them ahead of it** — a sweep that was
pre-loaded with its answers has not measured anything.

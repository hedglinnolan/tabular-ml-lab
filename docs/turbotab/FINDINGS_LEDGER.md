# TurboTab findings ledger

> This is the **TurboTab transition** ledger. It is not the app's own defect ledger —
> that lives at `docs/FINDINGS_LEDGER.md` and still has an open tail on the multi-file
> import path. See `TRANSITION_PLAN.md` §05 before touching that code.

Why this file exists: the transition from the Streamlit app to TurboTab is a delicate
process, and a finding that is documented but not tracked is a finding that gets lost.
Every finding from the architecture analysis lands here with a disposition. Nothing is
closed without a regression test named after it.

Baseline: `origin/main` @ `24c3446` (PR #145 merged).

Status values: `OPEN` · `PARTIAL` · `FIXED` · `WONTFIX` (with reason) · `NOT-A-DEFECT` · `UNVERIFIED`


## Governing rule (inherited)

> The app may be **silent**, and it may **refuse**, but it must never **assert something false**.

# `clinical_risk.csv` — expected findings

**480 rows × 11 columns.** A 30-day readmission cohort: `encounter_id`, `age`,
`sex`, `charlson_index`, `prior_admissions_12mo`, four labs
(`albumin_g_dl`, `creatinine_mg_dl`, `hemoglobin_g_dl`, `sodium_mmol_l`),
`length_of_stay_days` and the binary outcome `readmit_30d`.

Generated by `make_fixtures.py::clinical_risk`, seed `20260802`.

**Why it exists.** `GUIDED-135`. `leaky_sepsis.csv` is the fixture behind every
calibration claim made from a real project in this repository, and its held-out
C-statistic is **1.000** — complete separation on 24 rows with 16 events. So
`weak_calibration` returns `(None, None)`, the annotation box renders *not
estimable* for the intercept and the slope, and the `annotation_box` checklist
item **fails**. Every one of those behaviors is correct. The consequence is not:
the flagship clinical figure had been asserted for six loops only in the state
where two of its seven required numbers cannot exist, so **no fixture in this
repository could show the figure passing its own checklist.**

This is `GUIDED-097`'s fixture rule at the opposite polarity. That rule came
from *do not verify against the fixture that works*; this is the mirror — **the
fixture that degenerately fails.**

`leaky_sepsis.csv` keeps its job. It is the right fixture for leakage and for
the not-estimable branch, and that branch is a real path worth holding.

## The shape, measured

On the sealed 25% holdout with `logreg`, split at `numpy` seed 42:

| Property | Value | Why it is here |
|---|---|---|
| held-out rows / events | **120 / 31** | enough events that the two-parameter weak-calibration fit is defined rather than divergent |
| C-statistic | **0.719** | ordinary. A 30-day readmission model is a C ≈ 0.65–0.70 problem in the literature; a fixture that separates proves nothing about the figure and one at chance proves nothing either |
| calibration intercept | **+0.034** | the mean predicted risk matches the observed rate |
| calibration slope | **0.795** | below 1 — the small-sample overfitting signature the figure's caption exists to explain, arriving honestly |
| E:avg / E:max | **0.066 / 0.365** | both defined, so the annotation box has all seven numbers |
| event fraction | **0.233** (112/480) | a base rate the `-1.35` intercept can be read off directly |

The outcome is drawn Bernoulli from a logistic model of the predictors, so the
true risk is **genuinely partly unpredictable**. That is the property
`leaky_sepsis.csv` deliberately lacks: there `abx_escalation_score` carries
r = 0.9996 with the outcome, which is that file's whole purpose.

## Must surface

- `calibration` **admitted with all five checklist items passing**, including
  `annotation_box` — the first fixture in this repository that does.
- `binary_text__sex` — `sex` is `F`/`M`. Real, ordinary in clinical data, and
  left in rather than encoded away, so the fixture exercises the path a clinical
  upload actually takes.
- `decision_curve`, `roc` and `forest` admitted and passing, as on
  `leaky_sepsis.csv` — the contrast between the two files must be confined to
  the calibration numbers.

## Must NOT surface

- **Any leakage finding.** No column here is measured after the outcome or is a
  proxy for it. Leakage is `leaky_sepsis.csv`'s job, and a second fixture
  carrying it would make both files about two things.
- **Any impossibility-band repair.** Every value is inside
  `ml/physiology_reference.py`'s plausible range; the implausible-value work
  belongs to `clinical_longitudinal.csv`, which seeds fourteen of them.
- `encounter_id` as a predictor — it is one level per row, so
  `turbotab/identifiers.py` excludes it with a sentence. That is the ordinary
  path rather than a property of this fixture, and it is noted only so a reader
  does not mistake the exclusion for something this file arranged.

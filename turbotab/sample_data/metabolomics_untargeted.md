# `metabolomics_untargeted.csv` — expected findings

**80 rows × 400 columns.** 72 participant samples and 8 pooled QC injections; 392
intensity features `mz_0001`…`mz_0392`; `sample_id`, `sample_type`, `run_order`,
`batch`, `age`, `sex`, `bmi`; outcome `responder` (binary).

Generated by `make_fixtures.py::metabolomics`, seed `20260728`. Regenerating
reproduces it byte for byte.

This file exists so a drive is a **comparison against a stated expectation**
rather than a guess about whether a missing finding is a bug. Everything below
was measured against the engine, not assumed.

---

## The shape, measured

| Property | Value | Why it is here |
|---|---|---|
| Intensity range | 49 – 6,253,692 | four orders of magnitude, log-normal by construction |
| Features with any blank | 304 of 392 | untargeted panels are mostly sparse |
| Highest per-feature missing rate | 55% | the lowest-abundance features |
| Spearman(missing rate, log mean abundance) | **−0.99** | left censoring, not randomness |
| Median \|r(log intensity, `run_order`)\| | 0.33 | 58% of features exceed 0.3 |
| Median RSD, pooled QC vs participants | 0.25 vs 0.59 | QC is one sample injected repeatedly |
| QC `run_order` positions | 1, 11, 21, 31, 41, 51, 61, 71 | every tenth injection, the usual convention |

QC rows carry no `age`, no `sex`, no `bmi` and no `responder`. They look like
participants in every other respect, which is the point.

---

## Must surface

1. **The wide shape is expected, not malformed.** 392 features across 80 samples
   is the shape of an untargeted panel. Without the lens the app proposes
   `melt_repeated` — see the false alarm below — and with it the shape is stated
   and left alone.
2. **Missingness is detection-limit shaped.** Blanks concentrate in the
   lowest-abundance features, at −0.99 rank correlation. The consequence is the
   finding, not the statistic: filling with a column median puts non-detections
   in the middle of the distribution. Left-censored, not missing at random.
3. **There is a run-order column, and intensity tracks it.** Detection is
   derived; correction is `offered` and never automatic, because it alters every
   value (`DOMAIN_PACKS.md` §07).
4. **The 8 pooled QC rows are not participants.** They must be excluded from
   modeling — `derived` confidence, because modeling them has no legitimate
   reading. They stay available for quality assessment.

## Must NOT surface

- **No impossibility findings.** Measured: 0. There are no clinical variables
  here with an impossibility band, and an intensity of 49 is a real
  measurement. The one advisory hit is `bmi` against its reference interval,
  which is correct and stays advisory.
- **No grain question answered for the user.** `grain.suggestion` returns an
  empty candidate list, which is right: one row per subject, no column repeats
  like a roster. Questions 4–7 do not fire.
- **No scaling menu.** The metabolomics lens converts *"which scaling?"* into a
  rendered skip carrying the Pareto convention — stated **as** convention, with
  auto-scaling offered beside it, never as *"you should use Pareto scaling"*.
- **No QC-RSD feature filter applied.** It is `offered`. It drops features, so
  it changes the analysis and must be chosen.
- **No imputation performed on the working table.** Detection-limit imputation
  is a statistical transform under constitution §06 and is recorded, then fitted
  inside the training folds.

## False alarms this fixture reproduces on purpose

| Finding | Severity | Ledger | What should happen |
|---|---|---|---|
| `wide_repeated_measures` — *"4 groups of columns look like repeated measures"*, proposing `melt_repeated` | info | — | With no lens it is offered and is wrong but harmless at `info`. Under the metabolomics lens it is reframed: `mz_0001` and `mz_0002` are different analytes, not one analyte measured twice. **`melt_repeated` is a pre-barrier structural repair that rebuilds the index**, so applying it here would be destructive. |
| `binary_text__sample_type`, `binary_text__batch` | warning | — | Correct readings. `sample_type` genuinely is binary text. Leave them. |

`wide_repeated_measures` fires because `_REPEAT_SUFFIX` in `ml/import_doctor.py`
matches a trailing one-or-two-digit run, so `mz_0001` parses as stem `mz_00`
plus `01`. Four such stems exist. This is the false alarm `DOMAIN_PACKS.md` §01
names as the lens's first payoff, and it is reproduced rather than avoided so
the payoff can be demonstrated.

Model families

Which model families should be fit and compared?

Each family brings its own assumptions about how nutrients relate to the outcome; fitting several shows what depends on them.

  • Linear modelgood fitOLS or logistic regression: one reportable coefficient per predictor, with intervals for inference.
  • Elastic netfair fitA penalized linear model: shrinks correlated nutrients together, tuned inside training folds.Penalized coefficients are shrunk and carry no confidence intervals.
  • Feature-wise regressionfair fitTests each exposure on its own, adjusted for the covariates, with Benjamini–Hochberg false-discovery control; no predictions.Each exposure is adjusted for the covariates but not for the other exposures: a separate question for each.
  • Boosted treesfair fitMany shallow trees: finds curves and interactions; gives no coefficients.No coefficients or intervals: effects are read from curves instead.
  • Random-intercept mixed modelpoor fitA random intercept per unit: model-based intervals when rows repeat, even within few units.No identifier repeats in these rows, so there is no unit for a random intercept; it is the linear model's fit.
  • GEE (exchangeable)poor fitPopulation-average effects, with intervals robust to how a unit's repeated rows correlate.No identifier repeats in these rows, so there is no within-unit correlation to model; it is the linear model's fit.
  • Screened elastic netpoor fitKeeps the features most tied to the outcome in each training fold, then an elastic net.Screening chooses the reported features from the outcome: under inference that is selection, refused for the reported model.

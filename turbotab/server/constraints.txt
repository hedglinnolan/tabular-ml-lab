# 2026-10-09, recommendation 10). This is a pip constraints file: it limits versions and installs
# nothing by itself, so it also covers the test-only libraries of requirements-dev.txt. The floors
# in requirements.txt say what TurboTab needs; this file says what was tested, so a library's new
# release can no longer change a result, or the committed OpenAPI document, between two pushes.
#
#   python -m pip install -c turbotab/server/constraints.txt -r turbotab/server/requirements.txt
#
# One file serves Linux, macOS and Windows on Python 3.12 and newer (the lines with a `;` apply to
# one platform). To update it, resolve afresh, run the full tier of CI on the result (the whole
# suite and the browser tests, .github/workflows/v2-full.yml: push the change to a branch named
# ci/full-something), and commit the file with whatever the new versions required:
#
#   uv pip compile turbotab/server/requirements.txt turbotab/server/requirements-dev.txt \
#       --universal --python-version 3.12 --no-header --no-annotate -o /tmp/constraints.body
#
# then replace everything below this header with that output. To move one library only, edit its
# line and check that the install command below still resolves. To bring a development
# environment to these versions:
#
#   python -m pip install -c turbotab/server/constraints.txt \
#       -r turbotab/server/requirements.txt -r turbotab/server/requirements-dev.txt

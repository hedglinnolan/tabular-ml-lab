# Development and test dependencies.
#
# These are not optional extras. Without them the suite does not merely skip a
# few tests — it reports a *different and misleading* baseline: 26 integration
# failures that look like real breakage, all of them a missing plotting import
# surfacing as a page that will not render. Installing matplotlib and plotly
# turned 26 failures into 0 while changing no application code.
#
# That is worse than a red test, because a stable-looking wall of failures gets
# adopted as "the baseline" and then every subsequent comparison is made against
# noise. It cost several move-then-verify comparisons in this work before the
# cause was found. See T0-ENV-001.
#
#     pip install -r requirements.txt -r requirements-dev.txt

# page at import and cascades into every AppTest that renders it.

plotly>=5.14.0

# ── the test harness ─────────────────────────────────────────────────────────

# own budget and reported nothing, which is what `TEST-061` was. The guard

# not a correctness one.
